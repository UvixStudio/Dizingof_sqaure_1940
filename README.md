# כיכר דיזנגוף 1940

שחזור תלת-ממדי מסוגנן של כיכר דיזנגוף בתל אביב בערך ב-1938-1940, לצפייה בטלפון (ג'יירו/מצפן או גרירה). Three.js, בלי תלות בשירותים בתשלום.

הרצה מקומית: `cd src` ואז `python -m http.server 8000` ופתיחת `localhost:8000`. ג'יירו ומצלמה דורשים https.

פירוט המבנה והכללים ב-`CLAUDE.md`. תמונות המחקר (`data/`) לא נכללות בריפו.
